# PhotoBunker New

PhotoBunker — mobile-first PWA для защищённой съёмки, заданий, работы с фотографиями, Photo Card, команд и автоматического удаления данных. Цель продукта и UX определяет владелец.

## Текущая точка работы

- Каноническая handoff-ветка: `handoff/owner-agent-2026-11-06`.
- Базовый сохранённый код: `53f7d696d385fd81d3611089873db425c9175e8d`.
- **Развёрнутое приложение и последние исправления находятся в `compat/assignment-release/`.**
- Корневые `apps/web` и `apps/api` — незавершённое PB2-архитектурное дерево. Оно не является текущим runtime сервера.
- Production URL: `https://photobunker.duckdns.org`.
- Последний развёрнутый release marker: `dock-pwa-20261105-1`.
- Приложение **не принято владельцем и не является production-ready**. Автоматические тесты не отменяют зафиксированные на реальном телефоне дефекты.

## Приоритет требований

При конфликте источников применяется следующий порядок:

1. последнее прямое решение владельца;
2. `ts_and_ux.md`;
3. актуальные `docs/15-*` и `docs/16-*`;
4. нормативные безопасность/хранение/архитектура в `docs/02-*`–`docs/13-*`;
5. legacy и исторические отчёты только как read-only evidence.

## Рабочий процесс

В проекте теперь два участника: **владелец и один агент**. Старый процесс ChatGPT/Codex/stacked PR отменён. Агент работает небольшими проверяемыми шагами, после каждого шага обновляет статус, выполняет соразмерные проверки, коммитит и отправляет ветку. UI-задача не считается выполненной без проверки владельцем на целевом телефоне.

Нельзя удалять данные, volumes, контейнеры, БД или очищать PWA/IndexedDB/OPFS без прямого подтверждения владельца. `_old/` и старый репозиторий — только для чтения.

## Клонирование текущей рабочей версии

```sh
git clone https://github.com/1troitsky/photobunker-new.git
cd photobunker-new
git switch handoff/owner-agent-2026-11-06
cd compat/assignment-release
```

Не начинайте с `main` и не переносите изменения из `compat/assignment-release` вслепую в корневое PB2-дерево. Сначала прочитайте handoff и выберите один вертикальный сценарий.
