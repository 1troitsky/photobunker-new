# Historical implementation handoffs

Эти документы перенесены из верхнего уровня `docs/`, чтобы старые Draft PR, ChatGPT/Codex и stacked-branch инструкции не выглядели текущим процессом.

Они сохраняются только как implementation/security evidence. Любой указанный в них статус нужно перепроверять по текущему коду и `docs/15-CURRENT-IMPLEMENTATION-STATUS.md`; текущая работа определяется `ts_and_ux.md` и `docs/16-OPEN-PROBLEMS-AND-QUICK-TASKS.md`.
