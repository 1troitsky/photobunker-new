# Исторические документы

Эта папка хранит прежние аудиты, планы, отчёты этапов и старый процесс. Они нужны как evidence: SHA, результаты тестов, найденные дефекты и принятые на тот момент решения.

Исторический документ **не является текущим статусом**, даже если в нём написано «этап завершён». Актуальная точка входа: `README.md`, `AGENTS.md`, `ts_and_ux.md`, `docs/00-START-HERE.md`, `docs/15-CURRENT-IMPLEMENTATION-STATUS.md`, `docs/16-OPEN-PROBLEMS-AND-QUICK-TASKS.md`.

Упоминания ChatGPT, Codex, stacked PR и старой трёхсторонней схемы относятся только к истории до решения владельца от 2026-11-06.

- `2026-11-04/` — поэтапные аудиты и отчёты прежней сессии;
- `implementation-handoffs/` — старые технические handoff-документы Draft PR/PB2. Они сохраняют полезные security и implementation details, но их process/status указания отменены.
