## Утверждённые правила интерфейса

1. **Используемые лимиты**: демонстрационный **Go**, **15 ГБ / 30 ГБ** и **125 / 250 файлов**, оба по **50% использовано** справа от значения. Два прогресс-бара. Free/Go/Pro используют свои квоты; у Unlimited полоса количества файлов всегда пустая, количество не ограничено, но облако до 1 ТБ. Не писать «Тариф N · доступно X».
2. **Очередь отправки**: слева «Открыть очередь», справа **3 файла · 612 МБ**; снизу **«После отправки будет занято 15,612 ГБ и 128 файлов.»**. 612 МБ — **локальные зашифрованные материалы, ожидающие синхронизации, без кэша**. Они не учитываются как уже занятые байты облака. Экран очереди показывает конкретные файлы и позволяет удалить выбранный после подтверждения; не удалять ничего автоматически.
3. **Резервные копии**: основной экран показывает **список карточек** (дата/время, размер, файлов, **автоматическая/ручная**), рассчитан по вёрстке на 1–3 в будущем. Никакого публичного Recovery Vault. «Управление копиями и автообновлением» открывает единую страницу.
4. **Управление**: текущий максимум **1** логическая копия, полный список с действиями **«Удалить» и «Восстановить»**, «Доступно создание резервных копий: N в неделю», «Создать резервную копию» с текстом о замене предыдущей **только после успешного создания/проверки** новой. Возможность 2–3 копий в будущем — только расширение UX, не новое текущее право тарифа.
5. **Расписание**: «Доступно автообновлений: N в неделю», кнопки **Пн–Вс** с квотами по тарифу: Go 1, Pro 2, Unlimited ежедневно; Free не имеет бэкапов. Ручная/автоматическая квоты независимы, но обновляют актуальный логический бэкап. Сервер обязан обеспечивать лимиты и авторитетную дату обновления.
6. **Зашифрованный кэш**: «Миниатюры и временные данные для быстрого просмотра»; **246 МБ** и кнопка **«Очистить кэш»** справа; ползунок «Минимальный — Авто — Максимальный». **Очистка не затрагивает очередь отправки, Recovery Key/ключи, локальные оригиналы, ещё не синхронизированные с сервером.** Кэш не входит в облачный лимит или 612 МБ очереди.
7. **Автоматическое продление хранения**: **постоянно включено для всех пользователей**, не является настройкой и не зависит от тарифа как разрешение включения. **Но само продление допустимо только при наличии прав, в рамках максимального срока тарифа/задания и действующего TTL**. Не делать скрытое продление immutable `expires_at` уже созданных файлов без отдельного security/API решения. См. [billing-контракт](../../product/BILLING-TARIFF-CONTRACT.md).
8. **Перенос/экспорт и удаление** остаются самостоятельными операциями. Кэш, локальный оригинал и облачный файл не смешивать. Все разрушительные действия — с подтверждением и корректным серверным ACK.
9. Сохранить общий Fieldwork Shell: **Header 64 px / Dock 82 px**, графитовые панели, зелёный акцент, среднее закругление, фиксированные **«Отмена» / «Сохранить»** над Dock, RU/EN-поиск конкретных настроек. Не вводить синюю тему/круглые кнопки.
