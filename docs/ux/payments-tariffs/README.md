## Согласованный UI

- Общий Fieldwork Shell: Header 64 px, Dock 82 px, бренд, системный статус, нейтральный тёмно-серый фон и зелёный акцент. **Никаких синих панелей и круглых action buttons**; используется умеренное закругление. Одна зелёная кнопка тарифа **«Тариф: Unlimited (267 дней)»** — пример состояния.
- Главная страница: текущий Unlimited, остаток периода, показатели заданий, количества файлов и облачной квоты, переходы к сравнению, продлению/смене и истории.
- Сравнение **Free / Go / Pro / Unlimited**: цены и лимиты, выбор **1 / 6 / 12 месяцев**, скидки, полная таблица возможностей, кнопка выбора тарифа.
- Продление / смена: изменение тарифа и оплачиваемого периода, отображение стоимости и скидки; затем демонстрационное оформление.
- Checkout/завершение — только интерактивная имитация, **без настоящего платежа, ввода реквизитов, активации плана и серверных операций**. Бесплатный тариф не требует способа оплаты.
- История платежей: вымышленные операции и подробности; настоящих квитанций нет.
- Резервное копирование: **одна зашифрованная логическая копия**, которую разрешено обновлять с разной частотой. Публичная фраза о льготном периоде: **15–60 дней**.

## Контракт для агента

Использовать как источник **продуктовой** политики только [BILLING-TARIFF-CONTRACT.md](../../product/BILLING-TARIFF-CONTRACT.md): Free/Go/Pro/Unlimited; цены и скидки; квоты, Unlimited 1 ТБ; backup, Emergency PIN, отдельные grace 15/15/30/60 дней и 15-дневное окно downgrade. Устаревшие цены в `compat/assignment-release/apps/web/src/payments/catalog.ts` **не действуют**.

UI является демонстрацией с фиктивными данными, не платежным SDK. Production биллинг, ACL, E2EE, TTL/GC, хранилище, безопасная оплата, ledger и провайдеры реализуются отдельной задачей. Не менять работающий runtime или `main` ради фиксации UX.
