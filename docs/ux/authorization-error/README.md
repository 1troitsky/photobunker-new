## Утверждённая страница

1. **Полный экран вне авторизованного Shell** — нет обычных Header, Dock, тарифа, меню или дополнительного управления. Стиль Fieldwork: фон `#121212`, нейтральный графит и зелёный акцент, аккуратная геометрия в 320px и Desktop.
2. На странице только логотип **PhotoBunker**, компактный индикатор ошибки, **заголовок**, **чёткое объяснение** и **одна ссылка** «На страницу приветствия» (переход к уже принятому Welcome 1.4). Нет альтернативных кнопок «Повторить», «Удалить», «Сменить ключ».
3. Тексты зависят от подтверждённого типа сбоя. Состояния из HTML:
   - `key` — ключ аккаунта неверный, повреждённый или не подходит;
   - `lost` — ключ отсутствует/утрачен на этом устройстве;
   - `deleted` — аккаунт удалён;
   - `device` — это устройство отключено от аккаунта;
   - `emergency` — введён PIN экстренного удаления, доступ с устройства прекращён;
   - `local` — повреждены или недоступны локальные данные авторизации.
4. **Нельзя предполагать необратимую потерю облачных данных** только по сбою локального хранения, ошибке сети или по одному вводу аварийного PIN без подтверждения сервером. При удалённом аккаунте / отозванном устройстве и аварийном PIN прекращение доступа сообщается на основании достоверного состояния; невозможность восстановления не утверждается без доказанного состояния резервной копии.
5. **Верхний список причин** и **Телефон / Desktop** — только элементы предпросмотра для проверки вариантов. В production причина приходит из Identity/Device/Session, пользователь не выбирает её вручную. Отображение зависит от подтверждённой доменной ошибки, не от общей network/timeout ошибки.
6. Вернуться на Welcome можно единственной ссылкой. Если сессия отозвана, сначала блокировать доступ к закрытым экранам; не показывать ранее доступный приватный контент под error overlay.
