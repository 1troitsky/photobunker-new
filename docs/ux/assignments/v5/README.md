## Медиа и прогресс

- Независимые разрешённые виды материалов: **Фото, Видео, Аудио**. В списке показывать только включённые в настройках задания типы; для каждого — **фактическое количество** и, если задана, **необязательная числовая цель**.
- Цель нужна **только для оценки выполнения**, а не как лимит загрузок. В редакторе фото допускает 1–9999, видео/аудио 1–999; пустая цель означает отсутствие целевого процента.
- Для типов с заданной целью показать `фактическое / цель` и маленький progress bar; **без цели — только количество файлов, без искусственной шкалы**.
- **Общий прогресс** в принятом прототипе считается по целевым типам: `sum(min(count, target)) / sum(target)`, округляется до целого %. Виды без цели **не входят** в знаменатель и числитель. Если ни у одного типа нет цели, общий процент/полоса отсутствуют.
- В реальном приложении подсчитываются только соответствующие заданию **подтверждённые и доступные файлы/receipts**, отдельно по типам. Не считать локальную очередь, дубли редакций, временные черновики или неавторизованные записи как подтверждённый прогресс. Это backend/Local-First контракт, **не готовая реализация** в HTML.
- Список содержит сценарии смешанного задания, задания **только с аудио и без числовой цели**, запланированного задания и завершённого задания.

## Сроки и автоудаление

- **Начало**, **Окончание/«По автоудалению»** и **Длительность** в строке дат.
- При явной дате окончания именно она определяет показанное завершение. Если даты окончания нет, но есть автоудаление файлов или задания, на макете эффективным завершением выступает **более ранний** из этих дедлайнов; без них — «Без срока». Дата окончания и автоматическое удаление **не одно и то же**.
- Отдельные компактные пометки **«Файлы: [дата]»** и **«Задание: [дата]»** при включённых автоматических удалениях, без смешивания двух разных операций.
- Настройка **«Удалить также файлы задания»** из Editor 2.2 отражена в подробностях задания. Без отдельного подтверждённого права не удалять персональные копии других участников. **Автоудаление файлов само по себе не означает удаление задания**, и наоборот.
- В production deadlines — серверные, включая политики задания, TTL каждого файла, grace period/тариф, часовой пояс, revocation и безопасный GC. Демонстрационные даты в макете нельзя использовать как реальные триггеры.

- Внутри одного HTML работают вкладки, поиск, сортировка, меню, детали, дублирование, ручное завершение/возобновление и демонстрационное удаление с подтверждением. Изменения действуют **только на данные в памяти страницы**.
