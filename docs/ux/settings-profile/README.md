## Зафиксированная структура

1. **Settings**: вверху карточка своего аккаунта, которая открывает профиль. Главный раздел **«Профиль и люди»** содержит «Настройки профиля» и переход в уже отдельный UX **«Контакты и Команды»**. Остальные настройки — будущие разделы, не реализованные в этом HTML.
2. **Header**: неизменный Fieldwork Shell (64 px), бренд и системный статус; справа поиск настроек и одна зелёная кнопка **«Тариф: Unlimited (267 дней)»**. Значение тарифа демонстрационное, не настоящее состояние подписки или оплаты.
3. **Карточка**: свободная центральная композиция без контейнера вокруг аватара; крупный `@username` с копированием, ниже малый восьмизначный **числовой** `#UserID` с копированием, онлайн-индикатор / приблизительная активность, отключённые кнопки «Написать» и «Позвонить».
4. Далее — отдельные блоки **«О себе»** (или нейтральная заглушка), **три текстовых действия с иконками** («Поделиться профилем», «Добавить в контакты» / «Удалить из контактов», «Заблокировать контакт» / «Разблокировать контакт») и **список команд**, если это позволяет настройка приватности. Присутствие действий на собственной карточке — поведение текущего демо, а не подтверждённое production-правило.
5. **Настройки профиля**: аватар, имя, `@username`, описание, кому видна карточка, кому видны команды, видимость онлайн-статуса. Отдельного пункта «Карточка профиля», поля редактирования User ID и переключателя «Показывать последнее посещение» нет.
6. Для карточки и команд предусмотрены видимости: **всем / контактам / контактам и участникам команд / никому**. Для присутствия — доступные в демо варианты; при скрытии показывается приблизительное «Был недавно» / «Был давно», без точной даты.
7. Имя пользователя в будущем: 3–15 символов из `a-z`, `0-9`, `.`, `-`, не начинать и не заканчивать точкой/дефисом. User ID — неизменяемые **8 цифр**, не UUID. Серверную валидацию и права доступа нужно отдельно привести к согласованному контракту; данный PR их не меняет.

## Границы и ограничения

- Макет использует вымышленные данные, состояние текущей вкладки браузера и демо-действия. Не обеспечивает реальное публичное распространение профиля, сохранение на сервере, проверку авторизации/видимости, платежи, E2EE, звонки или сообщения.
- **Не переносить без отдельной задачи** в `compat/assignment-release/`. Не менять `main`, правила криптографии, ACL, Identity, TTL и Local-First ради макета.
- Часть визуальных деталей ещё требует повторного review владельца. В частности, наличие строки действия на своей карточке и оформление трёх ссылок остаются **WIP**, даже если исходный HTML сохранён.
